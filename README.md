## Что реализовано

- HTML/CSS/JavaScript в стиле лабораторной №1;
- Canvas с областью варианта и отображением проверенных точек;
- X: кнопки `-5, -4, -3, -2, -1, 0, 1, 2, 3`;
- Y: текстовое поле, диапазон `[-3; 3]`;
- R: текстовое поле, диапазон `[1; 4]`;
- AJAX-запросы методом POST;
- серверная валидация X, Y и R;
- Java FastCGI-сервер;
- история результатов между запросами;
- серверное время и время выполнения запроса;
- Apache httpd для статических файлов и перенаправления динамических запросов.

## Структура

```text
public/                 HTML, CSS и JavaScript
src/app/                исходный код Java FastCGI
scripts/build.sh        сборка JAR
scripts/deploy.sh       развёртывание на Helios
lib/                    сюда нужно положить fastcgi-lib.jar
httpd.conf              конфигурация Apache
```

## Сборка

1. Скопировать библиотеку из материалов лабораторной в `lib/fastcgi-lib.jar`.
2. Выполнить:

```bash
chmod +x scripts/*.sh
./scripts/build.sh
```

Результат появится в `build/lab2.jar`.

`scripts/deploy.sh` и в адресе страницы.

## Формулы области

Точка попадает в область, если выполняется хотя бы одно условие:

```text
III четверть: -R <= x <= 0 и -R/2 <= y <= 0
II четверть:  -R/2 <= x <= 0, 0 <= y <= x + R/2
I четверть:   x >= 0, y >= 0, x² + y² <= R²
```

Границы включены в область.
